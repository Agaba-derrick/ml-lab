🎓 Understanding the Basics

What is Machine Learning?

Forget the scary math for now. Here's the intuition behind what your code actually did.

🧠

Machine Learning (ML)

Instead of writing rules like if petal > 2cm → not setosa, you give the computer examples (data) and let it figure out the rules itself. That's ML!

📋

Dataset

A table of examples. Each row is one flower. Each column is a measurement (called a feature). The last column is the answer (called the label or target).

🏋️

Training a Model

You split the data: 80% goes to training (the model learns from this), and 20% goes to testing (you check if it learned correctly — data it's never seen!).

🎯

Accuracy

After training, you test the model on the 20% it hasn't seen. If it gets 97 out of 100 right, the accuracy is 97%. Higher = better!

🌳

Decision Tree

Like a flowchart of yes/no questions: "Is petal length < 2.5? → Yes → it's Setosa!" Easy to understand, just like a game of 20 questions.

🔵

KNN (K-Nearest Neighbors)

Find the 5 most similar flowers in the training data and take a majority vote. If 4 of them are Virginica → predict Virginica. Simple!

🌺 Flower Biology

What Are We Measuring?

The 4 features in our dataset correspond to real parts of the Iris flower.

Simplified Iris flower diagram

Sepal Length (4.3 – 7.9 cm)

The outer leaf-like parts of the flower. They protect the bud before it blooms. Sepals are usually green, but in Iris they look similar to petals.

Sepal Width (2.0 – 4.4 cm)

How wide the sepal is at its widest point. Setosa tends to have wider sepals compared to its length.

Petal Length (1.0 – 6.9 cm)

The most important feature! Setosa petals are tiny (~1.4 cm), while Virginica petals can be huge (~5.5 cm). This is the best separator.

Petal Width (0.1 – 2.5 cm)

How wide the petal is. Combined with petal length, this pair of features can classify flowers with near-perfect accuracy!

📖 Key Terms

ML Glossary for Beginners

Every term you've seen in this project, explained simply.

🎓 Machine Learning
Teaching a computer to learn from examples (data) instead of programming explicit rules.
📋 Dataset
A table of examples used for training. Rows = samples, Columns = features + label.
🔢 Feature
An input variable the model uses to make predictions. (e.g. petal length)
🏷️ Label / Target
The output we want to predict. In Iris, this is the species name.
🏋️ Training
The process of showing the model many examples so it learns patterns.
🧪 Testing
Evaluating the model on data it has never seen, to measure real performance.
🎯 Accuracy
Percentage of correct predictions out of total predictions. 97% = 97 right out of 100.
🌳 Decision Tree
A model that makes predictions using a series of yes/no questions (like a flowchart).
🔵 KNN
K-Nearest Neighbors. Finds the K most similar training samples and takes a majority vote.
📊 Confusion Matrix
A table showing which species the model confused with which. Diagonal = correct predictions.
📈 Classification Report
Detailed stats per class: precision (when it says X, is it X?), recall (how many X did it find?).
🔮 Prediction
What the trained model outputs when given new, unseen data.
